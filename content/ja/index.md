# Let's Start Functional

*Idris 2で線形時間の正規表現エンジンを作りながら，関数型プログラミングを学んでいく本です．テストファーストで，一歩ずつ進めていきます．*

関数型プログラミングには，「美しくて強力らしいけど，入門が難しい」という評判があるかと思います．モナドをブリトーで説明するチュートリアルだったり，"hello world"より先に出てくる型理論だったり．この本では逆のアプローチを取ります．**小さくて，本物で，役に立つものをひとつ**（正規表現エンジンです）作りながら，言語機能には必要になったタイミングでその都度働いてもらう，というスタイルです．

最後の章を読み終える頃には，Idris 2で以下のものが書き上がっているはずです:

- **完全な正規表現エンジン**．文字クラスもエスケープも回数指定も全部入りです．入力を**左から右へ一度だけ走査**してマッチするので，実在のサービスを落としてきた壊滅的なバックトラッキングとは構造的に無縁です
- 1画面ぶんくらいのコードで書く**パーサコンビネータライブラリ**
- エンジンの一部が正しいことの**機械検証された証明**．例でテストするのではなく，すべての入力について*証明*します
- 総仕上げとして，エンジンの上で動く**レキサ(字句解析器)**

すべての機能は失敗するテストから始まります．リポジトリのコミット履歴が*そのまま*チュートリアルになっていて，各ステップは小さなred/greenコミットとして再生できます．

## 誰のための本?

JavaScriptでもPythonでもRustでもJavaでも，何かしらの言語でプログラムが書けて，関数型プログラミングが気になっている方を対象にしています．**Haskellの知識も，圏論も，Idrisの経験も必要ありません．**関数型に一度挫折したことがある方にこそ，読んでもらいたい本です．

## 読み方

章は積み上げ式なので，順番に読んでいってください．各章のリズムは同じで，こんな感じです:

1.まだ答えられない問い，
2.その問いを固定する失敗するテスト，
3.それに答える最小限のコード，
4.そして，言語がいま何をしてくれたのかの振り返り．

「やった!ここまで動くようになった！」というのを小さく繰り返していくイメージです！

まずは[なぜ関数型?なぜIdris?](./01-why-functional.md)から始めましょう．
