# Let's Start Functional

*Idris 2 で線形時間の正規表現エンジンを作りながら、関数型プログラミングを学ぶ — テストファーストで、一歩ずつ。*

関数型プログラミングには評判があります。美しく、強力で、そして入門できない。ブリトーでモナドを説明するチュートリアル。"hello world" より先に来る型理論。この本は逆の道を行きます。**小さくて、本物で、役に立つものをひとつ**——正規表現エンジン——を作り、言語機能には作りながら働いてもらいます。

最終章まで読み終えたとき、あなたは Idris 2 でこれらを書き上げています:

- **完全な正規表現エンジン** — 文字クラスもエスケープも回数指定も全部入り。入力を**左から右へ一度だけ走査**してマッチし、実在のサービスを落としてきた壊滅的バックトラックとは構造的に無縁;
- 1 画面ぶんのコードで書く **パーサコンビネータライブラリ**;
- エンジンの一部が正しいことの**機械検証された証明** — 例でテストしたのではなく、すべての入力について*証明*;
- エンジンの上に組む、動く**レキサ(字句解析器)** — 総仕上げです。

すべての機能は失敗するテストから始まります。リポジトリのコミット履歴が*そのまま*チュートリアルです — 各ステップは小さな red/green コミットとして再生できます。

## 誰のための本?

JavaScript でも Python でも Rust でも Java でも、何かでプログラムが書けて、関数型プログラミングが気になっている人。**Haskell の知識も、圏論も、Idris の経験も要りません。** 関数型に一度挫折したことがあるなら、この本はあなたのために書かれました。

## 読み方

章は積み上げ式なので、順番に読んでください。各章のリズムは同じです:

1. まだ答えられない問い、
2. その問いを固定する失敗するテスト、
3. それに答える最小限のコード、
4. そして、言語がいま何をしてくれたのかの振り返り。

[なぜ関数型?なぜ Idris?](./why-functional.md) から始めましょう。
